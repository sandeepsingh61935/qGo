4-step process (industry)

  1. Understand problem & scope — FR, NFR, out of scope
  2. High-level design — components + data flow, get buy-in
  3. Deep dive — bottlenecks, failure modes, core algorithms
  4. Wrap-up — bottlenecks, improvements, monitoring
